These are short, licensed additions, not dialogue from One Piece, Dragon Ball, Naruto or Tamil films. Those specific works need permission or licensed source recordings before redistribution.

To regenerate from the source list, first restore the current sound bundle, then run `pnpm pack:add-open-sounds`. The importer downloads only the listed sources, cuts each at the documented point, converts to mono 22.05 kHz WAV, computes matching DSP features and keeps source/credit metadata in the pack.
